A black-and-gold mourning ribbon across the top-left corner of your site, in memory of Eric Binnion.

== Description ==

Activate the plugin and a black ribbon with gold trim and the words "R.I.P. ERIC" appears across the top-left corner of every page. It links to https://friendsofericbinnion.wordpress.com/.

There are no settings. Deactivate the plugin to remove the ribbon.

== Installation ==

1. In wp-admin, go to Plugins → Add New → Upload Plugin and choose rip-eric.zip.
2. Activate it.
3. When you're ready to take it down, deactivate and delete it.
